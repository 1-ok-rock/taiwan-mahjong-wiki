# Taiwan Mahjong Wiki

An English-only educational website introducing Taiwanese 16-tile mahjong.

## Assignment goal
The main purpose is to demonstrate **reusable AI development instructions**, not merely a one-off website. Read [AGENTS.md](AGENTS.md) to see specific rules for language, structure, design, file names, citations, testing, and new page creation.

## Content
- [Home](index.html): overview, topic directory and client-side topic search.
- [Basic Rules](pages/basic-rules.html): 16-tile resting hand and 17-tile winning structure.
- [Tile Actions](pages/actions.html): Chi, Pong and Kong explained.
- [Glossary](pages/glossary.html): simple English reference terms.

## Technology and deployment
HTML5, CSS3 and vanilla JavaScript; no build system, external services or API keys. To publish on GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root). All local links use relative URLs and support repository subpaths.

## Reusability demonstration
After publishing, tell an AI assistant: "Read AGENTS.md and add an English-only page about flower tiles. Follow the existing page pattern, verify sources, explain variants, update the topic grid and test internal links." The new topic should look and behave like existing pages without requiring a redesigned website.

## Content policy
Some scoring practices and detailed call rules depend on house rules. Verify statements with suitable references before adding them. This project is educational and does not promote gambling.

## Academic integrity
Review AI-generated changes and document the role of AI according to course requirements.
