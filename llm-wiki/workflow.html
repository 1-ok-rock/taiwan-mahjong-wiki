From evidence to a teaching presentation

Topic: Taiwanese Mahjong. The process is reproducible and its limitations are disclosed: five public sources were manually paraphrased into structured notes; a deterministic Python build script indexed them. It was not an autonomous LLM API call.

Actual execution record — November 12, 2026

Five distinct source records ingested; nine topic categories indexed; 12 slide outlines generated.

Automated checks: five documents ✓, distinct URLs ✓, required concepts ✓, independent support for central claims ✓, 16-tile standard hand ✓, five sets + pair ✓, slide-source mappings ✓.

Interactive browser validation: not confirmed by the local automation environment. Please open and test the public pages in your own browser before submission.

Observed issue and design improvement

Most error-prone node: fact consolidation. The source rulesets disagree on scoring details including the minimum tai requirement. For example, Mahjong Wiki describes a minimum tai, while Hé Fēn's particular classic preset allows zero tai.

Change made: moved contradiction checks upstream, from final-slide review to pre-generation validation. The scoring slide now explains that a house ruleset must be specified rather than presenting a universal score table.

Why: it prevents a wrong claim from being repeated in multiple slides and preserves traceability to the original source.

Limitations

This is a structured educational Wiki, not a deployed agentic retrieval pipeline. Ingestion here means processing human-curated notes and retaining links, not scraping webpages or running a commercial LLM. The downloadable source package contains the Python build script, source records, generated JSON and a complete validation log.
